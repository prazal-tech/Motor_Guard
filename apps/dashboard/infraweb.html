Fault Code Reference

8 fault modes with priority-ordered detection and hysteresis confirmation.

FC0
Normal
All parameters within nominal operating bands. Green LED active.
FC1
Mechanical Jam
RPM stall (<30) + current >7.2A. Highest priority. Relay trips immediately.
FC2
Bearing Failure
High vibration (>0.8g) + RPM degradation. TL2–3 depending on severity.
FC3
Winding Overheat
Temp >75°C + current >5A. TL3 if current >6A.
FC4
Belt/Coupling Slip
RPM drop >15–30% with normal current. Mechanical drivetrain issue.
FC5
Supply Voltage Issue
Voltage outside 9.6–14.4V band. TL3 at critical, TL1 at warning.
FC6
Mechanical Looseness
High vibration with normal RPM and current. Mounting or coupling loose.
FC7
Runaway / Load Loss
RPM >20% above nominal + current <0.5A. Belt break or no load.

Roadmap
Phase 3 Suggestions

Recommended Upgrades

Drop-in improvements that stay within the same ESP32 + ThingSpeak ecosystem.

UP-01
Multi-Magnet RPM
Current: 1 magnet → 2–4 magnets
Update PULSES_PER_REV only. Better low-RPM resolution and faster stall detection. Zero wiring change.
UP-02
INA226 Current Sensor
Current: INA219 → INA226
Drop-in I²C replacement. 16-bit vs 12-bit. Built-in averaging. Same GPIO21/22 pinout.
UP-03
ADXL345 Digital IMU
Current: ADXL335 ADC → ADXL345 I²C
13-bit I²C with FIFO. Shares existing INA219 bus. Eliminates 32×200µs polling loop noise.
UP-04
Dual DS18B20 Probes
Current: 1 probe → 2 probes
Chain on same GPIO4 bus. Monitor winding AND bearing temp separately. Single 4.7kΩ pull-up still works.
UP-05
EMA Filter
Current: MovAvg[5] → EMA α
Tunable alpha for faster fault onset response. Single float per channel vs 5-element ring buffer.
UP-06
NVS Fault Logging
Current: volatile only → Preferences NVS
Persistent fault history survives power cycles. Built-in ESP32 library. No extra hardware required.
UP-07
MQTT Realtime Push
Current: HTTP GET 15s → MQTT instant
PubSubClient library. Same WiFi stack. Fault events push instantly. Bidirectional remote commands.
UP-08
Solid State Relay
Current: Mechanical relay → SSR 3–32V DC
Microsecond switching vs 10ms. No contact wear. Handles auto-restart cycling. Same GPIO25 logic.
